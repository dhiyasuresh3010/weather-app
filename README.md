## 📖 Project Description
The Weather App is a Python-based command-line application that allows users to retrieve real-time weather information for any city using the OpenWeather API.

The application displays important weather details such as temperature, feels-like temperature, humidity, wind speed, weather conditions, sunrise time, and sunset time. Users can search multiple cities without restarting the application.

## Features
✔ Real-Time Weather Information

✔ Search Weather by City Name

✔ Temperature Display

✔ Feels-Like Temperature

✔ Humidity Information

✔ Wind Speed Details

✔ Weather Condition Display

✔ Sunrise & Sunset Times

✔ Multiple City Search Option

✔ Error Handling for Invalid Cities

✔ OpenWeather API Integration

## Technologies Used
- Python
- Requests Library
- OpenWeatherMap API
- JSON Data Handling

## How to Run

1. Install requests:
   pip install requests

2. Add your API key in the code.

3. Run:
   python weather_app.py
