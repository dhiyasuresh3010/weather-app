# Weather App

A Python Command Line Weather Application that fetches real-time weather data using the OpenWeatherMap API.

## Features
- Search weather by city
- Temperature details
- Humidity
- Wind speed
- Sunrise and sunset time

## Technologies Used
- Python
- Requests Library
- OpenWeatherMap API

## How to Run

1. Install requests:
   pip install requests

2. Add your API key in the code.

3. Run:
   python weather_app.py
